# 对话脑图 · 1.9.1

## 改动

1.9.0 把“要点”分支名隐藏、直接显示长叶子正文，弱化了树的层级；提供给模型的目录又没有已有节点，同一观点的不同说法容易反复追加。

当前树按“主题 → 命名分支 → 短节点”展示，父子连线连接各个分支及节点。主题、分支均可折叠；说明文字默认隐藏，点击节点查看。原生暗色配色、字幕独立列与紧凑窗口切换沿用；入口统一称为“脑图”。

模型输出 text 用作短节点，通常 8–22 字；应用拒绝超过 40 字的叶子正文。detail 保存可选解释，最多 160 字，按需查看与完整复制。广告保持独立收起，已有主题/分支 ID 与节点位置保持，后续限定、更正、决定新增节点。

相关目录仍受 1,200 字符限制：包含主题、分支和选出的短节点，节点编号 P 为本次请求的只读引用；必要说明只取最多 64 字供去重比较。模型确认同一观点的重复或改述时，以 match 引用既有节点。应用只合并来源，不追加节点、不重写原文。新对象、数字、限定或更正不能当作重复。语义判断仍由模型完成，目录是有界样本，不能保证所有重复都被识别或所有分类正确。

候选要落入已有分支且未标为重复时，云端会再做一次专门的语义去重比较；审查只可标记原候选对应分支已有的 P 节点，不可更改候选文字、来源、主题、分支。一次整理每个批次最多增加一次请求（最多 512 输出 tokens），串行完成；新主题/新分支或已明确 match 的候选无需额外请求。审查失败沿用本地回退策略。本地保留单次生成、相同短节点及 match 协议。

总结继续约 30 秒集中提交一次，云端优先、本地回退。完整字幕保留在历史中；识别和翻译处理未修改。云端现在会收到所选旧节点及简短限定用于比较，完整旧脑图不会整体重发；配置与密钥存放方式不变。

## 验证

- 379 项所选串行测试通过，13.421 秒；新增测试先在旧实现上复现长正文、同义改述重复追加、去重引用越界与无节点目录问题，再验证节点长度、来源合并、稳定 ID、分支名称引用、带限定的只读目录，以及真实 HTTP 双阶段审查。所选测试不含七项会清空共用日志的测试与一项依赖已安装翻译资源的测试。
- 正式云端服务七阶段合成文本回放 11.983 秒完成：广告、编程 AI 条件、自然改述、新的能力/商业条件、再次改述、独立住房事件、明确否定更正。两轮改述未增加节点，新主题独立，新更正新增节点；旧标题、ID、无关话题及广告保持，未启动本地总结 worker。初版单次生成未识别必要条件的正反表述，因此增加有范围限制的单独去重审查；没有通过放宽重复节点断言来取得最终通过。
- 原生截图覆盖 980/780/620/300pt、分支概览、展开节点与说明、字幕切换及空白/整理中/暂停/错误状态。基准工具向自身窗口发送鼠标事件，成功展开训练数据分支与节点说明，核对原生文字确实出现；宽窄切换不取消正在进行的总结。
- 980×640pt 的原生字幕/节点文字边界实测互不重叠。较矮窗口默认折叠叶子，没有可测的原生叶子字段，其列布局依靠截图检查，未把未执行的边界测量报告为通过。
- 单次 1,000 条合成历史输入：首显 196.3ms，缩放 p95 17.8ms，悬停 p95 1.8ms；实时字幕仍最多 100 条。该测量不代表长时间实际录音或选中文字的表现。
- 本次未运行 VoiceOver 或键盘焦点逐项遍历；原生 SwiftUI 辅助功能树未在无辅助客户端的基准进程中展开，已改用实际鼠标事件检验披露操作。本地回退路径由测试覆盖，未重新进行本地模型真实推理。语义效果只验收本次云端样本，不保证长时间、多场景都准确。
