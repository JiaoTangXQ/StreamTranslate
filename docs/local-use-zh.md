# 本机使用

安装完成后，打开“应用程序”中的 `StreamTranslate.app`。它是菜单栏应用，
入口是屏幕顶部的字幕气泡图标；屏幕下方会出现可拖动的字幕浮窗。

1. 首次启动时，同意下载 Apple 的英语、中文翻译语言包，等待准备完成。
2. 点击菜单栏字幕图标，打开 Settings；也可激活 App 后按 **⌘,** 打开设置。
3. 翻译电脑播放的视频或会议时，选择 **System Audio**；翻译身边的人讲话时，
   选择 **Microphone**。首次开始时，按 macOS 提示授予对应的屏幕录制或麦克风权限。
   如果系统要求退出并重新打开，重新启动本 App。
4. 英文转中文字幕：识别语言选 **English**，中文目标选简体中文。
   默认使用 **英译中流式 / Apple Speech English**，适合本机 16GB 内存的增强组合。
   **英文流式 Metal（本机安装） / Nemotron Streaming English** 是另一个已安装的英文后端，
   并非所有内容的首次译文都更快。
5. 点击 **Start**，或按 **⌘⇧T** 开始/停止字幕。开始之前请等待模型和翻译准备完成。

中文转英文：选择 **中文**，模型选 **中译英流式 / Apple Speech 中文**。
从英文原生模型切换到中文时会自动选择这项；已手动选择的 Whisper 模型会保留。
它使用普通话语音模型，不等同于自动中英混说识别。首次可能需要安装系统语音资产。

自动判断中英文：选择 **自动**，不兼容的原生模型会切换到 **Whisper Small Multilingual**。
也可以手动选择 Whisper 识别固定中文，作为口音、专业内容或系统模型不可用时的回退。
没有下载过的 Whisper 模型会显示下载进度。
Large-v3 Turbo 是额外可选模型，选择它会另行下载。
这台机器目前系统盘余量较少，Turbo 的 Core ML 初始化在对照时两次触发磁盘保护，
未完成本机性能验证；日常先使用已配置的 Apple 路径，不把它当作已验收的升级。

模型下载完成后，识别和翻译都在本机运行。一般使用时保持 Diagnostics 关闭，
避免持续保存录音和详细管线证据。普通运行日志仍可能包含识别文字和译文，
位于文末所列的本机日志路径；关闭 Diagnostics 不等于关闭所有文字日志。

## 增强版的变化

- 实时阅读时保持稳定；句末历史与最终翻译使用识别器纠正后的原文。
- 已有足够上下文的新文字最多等待 600 毫秒便进入翻译调度，不再必须凑够五个英文词或十个中文字。识别、推理和显示仍各自需要时间。
- 草稿不翻译单个英文词或不足四个中文字符，避免“大”被过早翻译成“big”；完整短句在句末照常翻译。
- macOS 26.4 使用系统低延迟翻译策略；两个可选增强开关只在录制期间加载本地模型。

## 重新构建和安装

1.2.1 增加两个独立开关：**千问句尾复核**、**双向终稿增强**。先出快速字幕，随后在同一条字幕上校正，不会另添一条重复字幕。千问适用于 Apple / Nemotron 流式识别；Hy-MT 精修中英双向终稿。后台模型准备可能需要数秒到数十秒，未就绪的句子继续走系统路径。系统内存紧张时会释放增强模型，继续提供基础字幕，不在同一场录制中反复重载。

本机增强模型目前位于 **PortableSSD**，请保持磁盘连接；断开后 App 自动使用原有识别/翻译。设置开关不等于模型一定可用，页面会显示安装状态。复核临时音频仅写入本机私有目录，完成后删除；Diagnostics 关闭时不保存连续录音。模型并不保证每句都更准确，尤其同音词、否定和数字仍需注意。

原生运行时安装脚本为 `scripts/install-qwen-local.sh`、`scripts/install-hymt-local.sh`，接收已验证的本地运行时/模型路径；它们不是自动下载器。当前低开销组合为 Qwen3-ASR 0.6B Q8 和 Hy-MT2 1.8B Q4_K_M，均使用 Mac 的 Metal，不需要 NVIDIA/CUDA。7B 翻译模型在这台机器的长测中触发内存压力，不作为默认模型。详见本轮验收记录。

在项目目录执行：

```bash
./scripts/install-local.sh
```

仅构建 App：`./scripts/build-app.sh`，输出到 `build/StreamTranslate.app`。
命令行构建需要 Swift 6 和 macOS 26 SDK，不需要额外安装完整 Xcode。
安装脚本使用固定的本地签名证书；首次创建时，系统可能要求输入 Mac 登录密码。
密码应只输入到 macOS 的系统对话框。

安装后保留上一版 `/Applications/StreamTranslate.app.previous`；项目的 `build/enhancement-baseline/` 也保留本轮升级前的 App。回退前先退出当前 App，不要同时运行两个版本。

日志位置：`~/Library/Logs/StreamTranslate.log`。
