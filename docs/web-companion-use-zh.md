# 网页私密字幕：手机首次使用

适用版本：Mac 1.3.2 及以上；本机已更新至 1.4.2（16），2026-09-06。电脑做识别与翻译，手机只显示文字。不需要另购服务器、域名、Apple 开发者会员或安装第三方续签工具。

1.4.2 移除手机阅读页的固定头部与页脚：请先刷新手机上已打开的旧页面。Mac 重启后，快速连接需要新二维码；若提示未配对，在电脑重新生成并扫码即可，字号等阅读偏好不因重新配对而清除。

## 常用：相机扫码快速连接，不安装证书

1. Mac 和 iPhone 连接到同一可互通局域网。鼠标移入字幕窗，点击出现的手机按钮 →“快速连接手机”；也可从 Mac 菜单栏 → 手机字幕进入。
2. Mac 首次会说明 **HTTP 未加密** 的风险。仅在自己信任的网络选择开启，随后自动显示二维码；不必手填 IP、端口或配对码。
3. 用 iPhone 自带相机扫描，点击链接，网页自动配对并显示字幕。Mac 需要已开始翻译，否则显示等待字幕。到这里已经能使用，不需要添加图标或登录账号。
4. 手机显示已连接后，可在 Mac 点击“进入仅手机显示模式”。手机断开时电脑也不会恢复显示字幕。

网页由 Mac 自己提供，自动优先选择 Wi-Fi/有线网卡的私有 IPv4，端口 18444。添加主屏幕图标是可选操作，不是使用前提。微信扫码受内置浏览器和链接规则影响，**未验证为必定兼容**；打不开时改用自带相机/Safari。

快速模式的边界：

- 字幕和配对凭据未加密，网络攻击者可能窃听或篡改。一次性二维码只能防止普通未授权连接，**不能代替加密**。不要用于公共 Wi-Fi、敏感会议，不要开放路由器端口转发。
- 网页设置面板保留未加密标识，正常阅读不再固定占位。Mac 首次开启仍需确认 HTTP 风险。Safari 可能另有 HTTP 安全提示，不能保证所有设备零提示；不要为使用软件全局关闭浏览器安全保护。无法接受此限制时使用下面的 HTTPS 或原生方案。
- 快速配对最长 12 小时，服务端仅存内存；关闭/重启网页服务、切换连接方式后需要重新扫码。临时网络断线、页面重载/切回前台，在凭据仍有效且服务未重启时可恢复连接。
- HTTP 页面不具备自动保持亮屏能力；页面禁用该选项并解释原因。锁屏可能暂停，重新打开可恢复。长时间免操作阅读且希望系统允许保持亮屏时，使用 HTTPS；系统仍可能拒绝亮屏请求。
- Mac 切换网络后地址可能变化，关闭网页连接再点击快速连接，扫新码；不擅自改 VPN/DNS/防火墙。访客网络的设备隔离无法由二维码绕过。
- 新安装和旧 HTTPS 用户都不会被自动降级为 HTTP，只有在 Mac 明确启用快速连接才会使用该模式；模式/开关会记住。已启用者换到不可信网络前应关闭快速连接。

## 高级：HTTPS 加密连接

以下证书步骤仅用于加密方案，**不是快速扫码的必经步骤**。在 Mac 展开“高级：HTTPS 加密连接”，点击“使用 HTTPS 加密连接”，再进行以下操作。

## 先准备 Mac

1. 运行更新后的 StreamTranslate，菜单栏 → 手机字幕 → **网页版 · 免签名** → 高级：HTTPS 加密连接。
2. 点击“使用 HTTPS 加密连接”。使用本机 HTTPS 端口 18443，不会在 TLS 失败时开放明文接口，不配置路由器端口转发。
3. 确认手机和 Mac 在可互通的局域网。Mac 插网线、手机连接同一路由器 Wi-Fi 也可以。访客网设备隔离、VPN/代理、禁用 Bonjour/mDNS 或防火墙可能阻止连接。

本机预期地址为 `https://xxxdemac-mini.local:18443/`，**以 App 显示的地址为准**。Mac 必须保持开机、唤醒和服务开启。不能把 `localhost` 或 `127.0.0.1` 输入手机：那会指向手机自己。

## 第一次安装证书（每部手机一次，不是安装原生 App）

1. 在 Mac 点击“导出手机证书描述文件”。Finder 会选中 `.mobileconfig` 文件。
2. 右键该文件 → 共享 → 隔空投送，发送到自己的 iPhone。仅接受来自自己 Mac 的文件，**不要安装陌生人或不明网页提供的根证书**。
3. 在 iPhone 按提示进入设置 → 通用 → VPN 与设备管理，安装 StreamTranslate 描述文件；需要手机解锁密码时，由你在手机上输入。
4. 设置 → 通用 → 关于本机 → 证书信任设置，启用对应 **StreamTranslate Local** 证书的完全信任。

描述文件只有本机生成的公开根证书，没有私钥、设备管理、VPN 或录音权限。根证书包含本机 DNS 名称约束，签发密钥仅用于生成这一个服务器证书，**不写入磁盘或钥匙串**；持久化的只是该服务器叶证书私钥。导出证书的 SHA-256 可在 Mac 界面核对。

这是用户主动授予本地证书信任，不能由二维码或网页静默完成，也不要通过忽略证书警告来代替。证书有效一年，到期或电脑本地主机名改变时需要重置并重新安装；重置会解除网页配对。停止使用后可从“VPN 与设备管理”删除描述文件。根证书的信任属于系统设置，不是仅某个 Safari 标签页的偏好。

## 配对与添加到主屏幕

1. 在 Mac 的 HTTPS 高级选项点击“生成 HTTPS 配对二维码”。
2. 用手机相机扫描二维码，用 Safari 打开；正常情况下会自动配对。也可打开网页地址，输入 Mac 上的 8 位配对码。
3. Safari → 分享 → 添加到主屏幕，并使用“作为网页 App 打开”。名称可保留“私密字幕”。
4. 从新图标打开一次。Safari 与主屏幕网页可能使用不同的数据存储；若新图标内提示未配对，在 Mac **生成新码**，输入到该图标打开的页面即可。最多授权三个浏览器入口。

邀请仅使用一次、两分钟过期；连续六次错误会取消邀请。浏览器配对凭据有效 90 天，到期、清除网站数据或在 Mac 解除配对后重新配对即可，**不需要每周续签 App**。

不要把仍带配对片段的原始链接公开分享；不要在演示共享屏幕时展示二维码或配对码。二维码中的邀请片段由页面读取后立即移出地址栏；没有加入服务器访问日志。

## 正常看字幕

1. 在 Mac 选择麦克风或系统音频并开始翻译，手机打开“私密字幕”。手机不能自行开启录音。
2. 手机显示“已连接”后，在 Mac 点击“进入仅手机显示模式”。电脑字幕、历史和设置窗口收起；手机掉线也不会让电脑弹出字幕。
3. 手机轻点阅读区才显示右上角 Aa，点击调整字号、原文显示、保持亮屏；未打开设置时三秒不操作自动隐藏，展开后点“完成”关闭。控件不占字幕布局空间。
4. 拖动回看、确实离开最新位置时才显示“回到实时字幕”。手动滚回底部或点击提示都能恢复跟随；连续更新、设置面板内滑动不会误弹提示。
5. 切换 App/锁屏可能暂停连接；重新打开恢复当前字幕。断线会清空旧画面并显示恢复状态。系统拒绝保持亮屏时设置里会提示，不承诺绕过省电或后台限制。
6. 结束时在 Mac 停止录音；必要时关闭网页服务。退出“仅手机显示”仍从 Mac 菜单栏操作。

字幕只在网页运行内存中保留，不写入 localStorage、IndexedDB 或服务工作线程缓存。浏览器仍可能保留访问网址，系统也可能制作应用切换快照；页面会在离开时遮挡/清空，但系统级隐私表现仍需真机验收。若 Mac 离线时冷启动桌面图标，页面本身可能无法加载——它不是独立离线翻译 App。

## 无法打开时

- 出现证书警告：检查是否安装并信任当前 Mac 导出的证书；地址必须与 App 一致，不要替换成 IP 后忽略名称不匹配。
- 网页打不开：确认端口 18443 未被占用、Mac 本地网络权限/防火墙允许、两端不处于隔离网络；检查 VPN/代理是否允许局域网和 `.local` 解析。本轮不会擅自改变你的 VPN、防火墙或路由器配置。
- 能打开但没有字幕：先确认配对成功、Mac 已开始收音，并且语音/翻译语言包准备完成。
- 配对码失效：在 Mac 重新生成，或解除旧网页配对后再试。
- 不支持此路线：网页没有原生 Apple 点对点自动发现/直连接口，只使用正常可互通的局域网；原生 iPhone 开发版仍保留。
