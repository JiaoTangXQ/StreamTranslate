# 手机私密字幕开发计划

状态：2026-09-06 已完成第 1–5 步的代码和本机可执行验证，完整 Xcode 已安装，未签名 iPhoneOS 原生构建通过。按用户最新选择，先不连接手机，使用已安装的 iOS 26.5 模拟器继续界面、生命周期与合成字幕联调；第 6 步真机验收延后，不阻塞当前开发。详细边界见[开发状态](companion-development-status.md)。范围：Mac 持续翻译、原生 iPhone 只接收文本；不发送音频，不做云中转。

## 实施顺序

1. 使用 macOS 26 installedSource 会话解耦翻译与悬浮窗；未装语言包时只允许演示前准备。
2. 增加共享的有界字幕协议、序列/快照恢复、加密连接与安全配对；默认关闭服务，用户明确启动。
3. Mac 新增手机设置和“仅手机显示”模式；持久化私密模式，所有恢复/历史/设置入口受控，断线不恢复桌面。
4. iPhone 原生阅读与配对入口、自动重连、生命周期恢复和隐私遮挡。
5. 编译 Mac、共享核心/协议/安全/本机 TLS 集成测试；补充 iOS 工程和构建说明。
6. 在实际 iPhone、签名环境可用后验收双机无线、锁屏、两小时、共享接收端隐私与能耗。

## 本轮技术取舍

- 使用公开 Network.framework、TLS 1.3 与独立安装身份；证书使用 Apple swift-certificates 生成，不接受任意自签对端。
- 先实现 TCP + TLS 基线与显式 Apple P2P 选项；QUIC 与自动路径切换在双机基准验证后实施，不伪装为已完成。
- 配对二维码携带短期一次性邀请和服务端证书指纹，手机固定信任该指纹；已配对客户端持有 Keychain 凭据，Mac 可撤销。
- 手机无用户授权不能控制录音；第一版只读字幕。无鉴权连接不获得任何字幕。
- 无网络时不静默使用云端。手机掉线不停止 Mac 翻译，也不弹出电脑字幕。
- iPhoneOS 原生编译依赖完整 Xcode 与 iOS SDK；真机安装另需签名。工具现已安装，未签名构建通过，不能把它写成已交付可安装包。

## 验收门槛

- 连接、认证、快照、增量、清空/会话切换、修订更新、协议大小限制均有测试。
- 未配对、错误指纹、失效邀请、撤销凭据不获得正文；队列有界，慢客户端不阻塞翻译。
- 隐藏、重开、断线、下载状态变化不恢复字幕窗；OS 隐私指示不隐藏。
- iPhone 回前台主动恢复当前状态，后台挂起不视为永久连接保证。
- LAN/P2P 性能、能耗、屏幕共享共存、真机长时测试未通过前明确标记未验证。
